## 一、长期约定（每次发布/更新都必须遵守）

1. **发布动态格式**：每次发布后输出
   ```
   学习打卡表开发动态
   • <本次更新要点，一行一条>
   开发进展，具体上线以版本发布为准。
   提交时间：YYYY-MM-DD HH:MM:SS（北京时间）
   ```
2. **版本号规则**：小更新 1.1 / 1.2 …；重大重构 2.0 / 3.0。两处文件（云端版 `checkin-app/index.html`、离线版 `学习打卡表.html`）的 `VERSION` 常量与页脚徽章同步改。
3. **GitHub 同步**：每次发布后 `git add → commit（vX.Y: 要点）→ push origin main`，仓库 github.com/diorninger/checkin-app。
4. **两处产物同步改**：云端版与离线单文件版必须保持一致（离线版由 `gen_local.js` 从 index.html 生成）。
5. **素材规范**：图标/图片只用官方公开或合法授权渠道，不 AI 生成、不二次创作。
6. **数据口径**：所有数字（TOTAL、完成率、版本、日期）必须来自代码实际计算，缺失就写「暂缺」，不估算。
